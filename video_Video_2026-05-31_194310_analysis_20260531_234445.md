The user is attempting to attach files to download blocks within a lesson editor interface.

Here is a breakdown of their actions and the resulting problem:

1.  **First Attempt (Uploading a file):**
    *   The user clicks on the first block, labeled "Heart Sounds Quick Guide".
    *   In the "Block Settings" panel on the right, they click the **Upload** button under the "File" section.
    *   They select a file from their computer and upload it.
    *   A success message appears at the bottom right: **"File uploaded successfully"**.
    *   The user then clicks the **Save** button at the top of the screen.
    *   Another success message appears: **"Lesson content saved!"**.
    *   **The Problem:** Despite the success messages, the block itself and the Block Settings panel still display the text **"No file selected"**. The expected behavior is that the uploaded file's name should replace this text, indicating it is successfully attached.

2.  **Second Attempt (Selecting from Media Repo):**
    *   The user clicks on the second block, labeled "ECG Quick Guide".
    *   In the "Block Settings" panel, they click the **Media Repo** button.
    *   They select a file from the repository modal.
    *   A success message appears: **"File selected from media repository"**.
    *   The user clicks the **Save** button again.
    *   The success message **"Lesson content saved!"** appears.
    *   **The Problem:** Just like the first attempt, both the block and the settings panel continue to show **"No file selected"**.

**Summary of the Issue:**
The core problem is a disconnect between the system's success notifications and the actual state of the UI. The user successfully uploads or selects a file and saves the lesson, receiving confirmation messages for each step. However, the UI fails to update and continues to indicate that no file is attached to the download blocks.
