# AI Generation Workflow Audit

**Scope:** Railway-hosted UltrasoundAssist administrative and authoring workflows. This audit identifies generation paths, not customer content or credentials.

## Shared transport finding

Most text-generation procedures call the shared `invokeLLM` helper. With the Railway Forge URL and key configured, its automatic transport now uses Forge chat. The lesson editor is also explicitly pinned to Forge, preventing it from falling back to the task API when both credentials are present.

| Area | Workflows | Shared helper | Required outcome |
| --- | --- | --- | --- |
| LMS authoring | Lesson content, lesson quiz questions, flashcards, promotion copy | `invokeLLM` | Direct Forge chat response, administrator gate retained |
| Question Bank and Quiz Creator | Topic, document, image, and URL-driven question generation | `invokeLLM` | Direct Forge chat response with existing structured-output validation |
| Product and downloads administration | Sales-page blocks | `invokeLLM` | Direct Forge chat response with existing administrator gate |
| Email campaigns | Campaign copy and block regeneration | `invokeLLM`; image helper | Direct Forge chat and existing server-side image generation |
| Social content | Social copy and abstract images | `invokeLLM`; image helper | Direct Forge chat and existing server-side image generation |
| Clinical/community tools | Case creation, QuickFire questions, channel summaries, CME form content | `invokeLLM` or `invokeLlmJsonPrompt` | Direct Forge chat response and existing structured parsing |
| Forms and career tools | Form import/field expansion and resume drafting | `invokeLLM` | Direct Forge chat response with the existing role gate |

## Image generation finding

The shared image helper already uses the configured Forge API server-side when the configured endpoint is not OpenAI. Generated bytes are stored through the existing object-storage helper rather than in the database. It must be tested after the R2 repair is confirmed because image generation cannot return a usable image URL if object storage cannot accept the generated output.

## Excluded functionality

The LMS router contained a generator for synthetic customer testimonials and ratings. Fabricated reviews, ratings, and testimonials must not be generated or stored. That generator and its authoring entry points must be removed rather than migrated to Forge.

## Completed transport and safety changes

Forge chat is now the automatic shared preference whenever valid Railway Forge credentials are present, including where a legacy Manus task credential is also available. The AI connection check reports that same preferred transport. Text and image helper errors now provide a safe retry message to authors while logging only an HTTP status server-side.

The synthetic testimonial endpoint and its Landing Page Builder controls are removed. AI product and digital-download landing-page prompts no longer create review blocks, new funnel templates no longer add a testimonial block by default, and newly added review fields start blank for administrators to enter genuine content. Focused Forge, structured-generation, and funnel regressions pass (143 tests); affected client and server bundles compile successfully.

## Read-aloud finding

Quiz read-aloud remains available as a creator-controlled setting for native standalone quizzes. It defaults to **off** for newly created and previously unset quizzes. Creators can explicitly enable the learner-facing control and select one of two clear voice profiles: **Female** or **Male**. Explicitly saved creator choices remain unchanged. The learner can still decide whether to activate the offered read-aloud before starting an attempt.

The selected profile maps to a stable server voice when compatible speech synthesis is configured. That request now asks for warm United States English, natural unhurried pacing, sentence pauses, and careful clinical-term articulation. When server speech is unavailable, the existing browser fallback uses the closest available English voice with a calm 0.94 playback rate. Quiz questions, answer choices, attempts, scores, and existing result settings are unchanged.
